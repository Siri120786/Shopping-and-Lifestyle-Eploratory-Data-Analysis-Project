# Lifestyle & Shopping Data Analysis

This project focuses on Exploratory Data Analysis (EDA) of a Lifestyle and Shopping dataset. The objective is to analyze consumer behavior, shopping habits, spending patterns, and lifestyle-related factors through data visualization and statistical analysis.

The project includes:
- Data Cleaning and Preprocessing
- Missing Value and Outlier Analysis
- Customer Demographics Exploration
- Shopping and Spending Pattern Analysis
- Correlation and Feature Analysis
- Data Visualization using Python Libraries
- Basic Machine Learning Techniques for Insight Discovery

The primary goal is to extract actionable insights from lifestyle and shopping data, helping understand customer preferences and purchasing trends rather than building predictive models.
